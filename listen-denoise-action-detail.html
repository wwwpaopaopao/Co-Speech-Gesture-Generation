SIGGRAPH 2023

Listen, Denoise, Action! Audio-Driven Motion Synthesis with Diffusion Models

作者：Simon Alexanderson, Rajmund Nagy, Jonas Beskow, Gustav Eje Henter
机构：Motorica AB, KTH皇家理工学院
摘要： 我们提出了Listen, Denoise, Action!，一种基于扩散模型的音频驱动动作合成方法。 该方法通过创新的TISA（Translation-Invariant Self-Attention）Transformer架构，实现了高质量的音频到动作生成。 我们的方法在多个任务上取得了SOTA性能，包括对话手势合成、舞蹈生成和动作重定向。 同时发布了新的Motorica Dance Dataset高质量舞蹈动作捕捉数据集。

🎯 核心贡献

  • TISA Transformer架构 提出翻译不变自注意力（Translation-Invariant Self-Attention）机制，结合扩散模型实现高质量动作生成，支持任意长度的序列生成。
  • 统一生成框架 单一模型架构支持多种任务：对话手势、舞蹈生成、动作重定向，无需针对特定任务设计。
  • 高质量数据集发布 发布Motorica Dance Dataset，包含专业舞蹈演员的高质量动作捕捉数据。
  • 多模态条件控制 支持音频、风格标签、全局条件等多种条件输入，实现可控生成。

关键组件详解

🎵 音频特征提取

多维度音频特征表示：

  • 频谱特征 (Spectrogram)
  • 节拍特征 (Beat Activation)
  • 35维音频特征向量
  • 30fps时间对齐

🔄 扩散模型

基于DDPM的扩散过程：

  • 150个扩散步数
  • 线性噪声调度 (0.01→0.7)
  • 预测噪声而非直接预测动作
  • 支持条件生成和无条件生成

🧠 TISA Transformer

翻译不变自注意力机制：

  • 2个注意力块
  • 8个注意力头
  • 支持膨胀卷积 (Dilation)
  • 位置编码：正弦余弦编码

🎨 条件控制

多层次条件融合：

  • 局部条件：音频特征
  • 全局条件：风格标签
  • 扩散时间步嵌入
  • 支持风格插值

核心代码：TISA Transformer

class TisaTransformer(nn.Module): def __init__(self, in_channels, out_channels, d_model, num_blocks, num_heads, activation, norm, drop_prob, d_ff=2048, seqlen=128, use_preln=False, bias=False, dilation=1): super().__init__() self.in_proj = nn.Linear(in_channels, d_model) self.attention_blocks = nn.ModuleList([ AttnBlock(d_model, num_heads, activation, norm, drop_prob, tisa_num_kernels=21, seqlen=seqlen, use_preln=use_preln, d_ff=d_ff, bias=bias, dilation=dilation) for _ in range(num_blocks) ]) self.out_proj = nn.Linear(d_model, out_channels) def forward(self, x): x = self.in_proj(x) for layer in self.attention_blocks: x = layer(x) x = self.out_proj(x) return x

核心代码：扩散过程

def diffusion(self, poses, t): N, T, C = poses.shape noise = torch.randn_like(poses) # 计算噪声缩放 noise_scale = self.noise_level[t].unsqueeze(1).unsqueeze(2).repeat(1,T,C) noise_scale_sqrt = noise_scale**0.5 # 加噪 noisy_poses = noise_scale_sqrt * poses + (1.0 - noise_scale)**0.5 * noise return noisy_poses, noise def forward(self, batch): ctrl, global_cond, poses = batch # 随机采样时间步 t = torch.randint(0, num_noisesteps, [N], device=poses.device) # 加噪 noisy_poses, noise = self.diffusion(poses, t) # 预测噪声 predicted = self.diffusion_model(noisy_poses, ctrl, global_cond, t) # MSE损失 loss = self.loss_fn(noise, predicted.squeeze(1)) return loss

🔬 技术创新点

1. TISA (Translation-Invariant Self-Attention)

  • 翻译不变性：注意力权重仅依赖于相对位置，而非绝对位置
  • 高效计算：通过核函数分解降低计算复杂度
  • 长序列支持：能够处理任意长度的输入序列
  • 时间一致性：生成的动作在时间维度上更加连贯

2. 膨胀注意力机制 (Dilated Attention)

  • 多尺度感受野：通过不同的膨胀率捕获不同时间尺度的信息
  • 膨胀周期：[0, 1, 2] 循环使用，平衡局部和全局信息
  • 计算效率：减少参数量，提高推理速度
  • 层次化特征：不同层关注不同粒度的动作特征

3. 扩散模型架构

  • 残差连接：20层残差网络，稳定训练
  • 条件注入：在每一层注入音频和风格条件
  • 跳跃连接：聚合多层特征，提高生成质量
  • 噪声预测：预测噪声而非直接预测动作，训练更稳定

4. 多任务统一框架

  • 任务无关：相同的架构适用于不同任务
  • 条件灵活：通过条件输入控制生成内容
  • 风格插值：支持风格之间的平滑过渡
  • 可扩展性：易于扩展到新的任务和数据集

💡 应用场景

  • 虚拟数字人：为虚拟主播、虚拟助手生成自然的对话手势
  • 游戏开发：根据游戏音乐自动生成角色舞蹈动画
  • 影视制作：快速生成角色动作预演和背景人群动画
  • VR/AR应用：驱动虚拟形象进行实时动作表演
  • 动作重定向：将动作从一个角色迁移到另一个角色
  • 风格迁移：改变已有动作的风格特征
  • 动画辅助：为动画师提供动作参考和初始关键帧
  • 交互式娱乐：音乐驱动的实时舞蹈生成
