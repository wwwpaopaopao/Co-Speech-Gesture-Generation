ConvoFusion

Multi-Modal Conversational Diffusion for Co-Speech Gesture Synthesis

多模态对话扩散模型用于协同语音手势合成

📅 CVPR 2024 🏛️ MPI-INF 🔬 扩散模型 👥 多人对话

👥 作者团队

Muhammad Hamza Mughal Rishabh Dabral Ikhsanul Habibie Lucia Donatelli Marc Habermann Christian Theobalt

机构：Max Planck Institute for Informatics (MPI-INF), Germany

📋 论文概述

ConvoFusion 是首个针对多人对话场景设计的协同语音手势生成模型。与现有方法主要关注单人独白场景不同， ConvoFusion 能够同时建模说话者(speaker)和倾听者(listener)的手势，实现更自然的对话交互。

核心贡献：
  • 提出多模态对话扩散框架，支持说话者和倾听者的联合手势生成
  • 引入 Word Excitation Guidance (WEG) 机制，增强文本语义控制
  • 设计了 Text-Audio-Motion Fuser 模块，实现多模态信息的有效融合
  • 在 BEAT 和 DnD 数据集上取得 SOTA 性能

🎯 研究背景与挑战

现有问题

  • 单人场景局限：大多数现有方法仅关注单人独白(monologue)场景
  • 对话交互缺失：真实对话中倾听者也会做出手势反应(back-channeling)
  • 多模态融合不足：如何有效融合文本、音频、对话上下文仍是挑战
  • 语义控制弱：缺乏对特定词汇的手势生成控制机制
ConvoFusion 的解决方案：通过对话感知的扩散模型，同时生成说话者和倾听者的手势， 并引入词级语义引导机制，实现更细粒度的控制。

关键组件详解

1. TextAudioController

同时编码说话者和倾听者的文本与音频信息，通过时间投影对齐不同模态的时序特征。

  • 文本编码：使用 T5 或类似预训练语言模型
  • 音频编码：Mel-spectrogram + Conv 编码
  • 时间对齐：通过线性投影统一时序维度

2. TextAudioMotionFuser

融合文本、音频和运动信息，支持说话者(spk-ta)和倾听者(lsn)两种模式的条件注入。

  • 支持条件类型：说话者、倾听者、混合
  • 使用位置编码区分不同角色
  • Cross-attention 机制融合多模态

3. Denoiser (去噪网络)

基于 Transformer 的扩散去噪器，采用 Skip Transformer Encoder 结构。

  • 架构：Transformer Encoder
  • 位置编码：正弦位置编码 + 可学习编码
  • 支持 Classifier-Free Guidance

4. VAE (变分自编码器)

两阶段训练：先训练 VAE 压缩运动空间，再训练扩散模型在隐空间生成。

  • 编码器：将关节运动压缩到隐空间
  • 解码器：从隐空间重建关节运动
  • 支持 6D 旋转表示

Word Excitation Guidance (WEG)

WEG 是 ConvoFusion 的创新机制，允许用户对特定词汇增强手势生成：

  • 语义控制：通过注意力权重定位文本中的关键词
  • 手势增强：对关键词对应的时间区域增强手势幅度
  • 灵活调节：支持语义引导(semantic)和随机(random)两种模式

📊 数据集

BEAT Dataset

大规模多模态对话手势数据集

  • 76小时对话数据
  • 4种语言(英、中、日、德)
  • 丰富的语义和情感标注
  • SMPLX 身体参数

DnD Dataset

Dungeons & Dragons 多人对话数据集

  • 多人游戏对话场景
  • 自然的群体交互
  • 丰富的手势反应(back-channeling)
  • 适合对话场景研究

与 SOTA 方法对比

ConvoFusion 在以下方面超越现有方法：
  • 单人场景：与 HA2G、DiffGesture 等方法相比，FID 降低 X%
  • 对话场景：首个支持说话者+倾听者联合生成的模型
  • 语义控制：WEG 机制实现细粒度文本控制

训练流程

阶段1：训练 VAE

python -m train --cfg configs/config_vae_beatdnd.yaml \ --cfg_assets configs/assets.yaml \ --batch_size 128 --nodebug

阶段2：训练扩散模型

python -m train --cfg configs/config_cf_beatdnd.yaml \ --cfg_assets configs/assets.yaml \ --batch_size 32 --nodebug

推理测试

python -m test --cfg /path/to/trained-model/config.yaml \ --cfg_assets ./configs/assets.yaml

🔍 技术亮点

🎭 对话感知生成

首次实现说话者和倾听者的联合手势生成，捕捉对话中的互动模式。

📝 词级语义控制

WEG 机制允许对特定词汇增强手势，实现细粒度的语义控制。

🎵 多模态融合

创新的 TextAudioMotionFuser 有效融合文本、音频和运动信息。

⚡ 高效训练

两阶段训练策略(VAE + 扩散)提高训练效率和生成质量。
