CVPR 2023

TalkSHOW: Generating Holistic 3D Human Motion from Speech

作者：Haiyang Liu, Zihao Zhu, Naoya Iwamoto, Yichen Peng, Zhengqing Li, You Zhou, Elif Bozkurt, Bo Zheng
机构：Max Planck Institute for Intelligent Systems, MBZUAI, University of Tokyo, Microsoft Research
摘要： 我们提出了TalkSHOW，一种从语音生成全身3D人体动作的方法。 该方法能够同时生成面部（表情）、身体姿态和手部动作，实现真正的人体全身动画。 采用SMPL-X模型作为人体表示，通过VQ-VAE和PixelCNN实现高质量的全身动作生成。 支持英语、法语、歌曲等多种语言和形式的语音输入，具有良好的泛化能力。

🎯 核心贡献

  • 全身动作生成 同时生成面部（表情）、身体姿态和手部动作，实现真正的人体全身动画。
  • SMPL-X人体模型 使用SMPL-X作为统一的人体表示，包含面部表情、身体姿态和手部姿态。
  • VQ-VAE + PixelCNN架构 使用VQ-VAE对身体动作进行离散化编码，然后使用PixelCNN进行序列生成。
  • 多语言泛化能力 支持英语、法语、歌曲等多种语言和形式的语音输入。
  • 分离式生成策略 面部和身体分开生成，身体部分再细分为身体姿态和手部动作。

关键组件详解

🎭 面部生成器

专门的面部动画生成网络：

  • 表情参数：100维
  • 下巴姿态：3维/6维
  • 眼睛姿态：6维/12维
  • 基于Transformer的生成器

🧍 身体VQ-VAE

身体动作离散化编码：

  • Codebook大小：2048
  • 嵌入维度：64
  • 分离式：身体+手部
  • 1024维隐藏层

🎨 PixelCNN生成器

自回归序列生成：

  • 2048个类别
  • 512维隐藏层
  • 10层网络
  • 音频条件输入

🎵 音频特征

MFCC音频表示：

  • MFCC特征：64维
  • 音频编码器
  • 256维隐藏层
  • 时间对齐

📊 实验设置与结果

数据集：SHOW Dataset

数据规模

  • SHOW Dataset v1.0
  • 多说话者数据
  • 全身动作捕捉
  • 面部表情数据

SMPL-X参数

  • 表情：100维
  • 身体姿态：63维
  • 手部姿态：90维
  • 全局朝向：3维

输出表示

  • 3D/6D旋转表示
  • 88帧序列长度
  • 30fps帧率
  • SMPL-X格式

训练配置

# VQ-VAE配置 (body_vq.json) { "Model": { "model_name": "s2g_body_vq", "composition": true, # 分离式身体+手部 "code_num": 2048, # Codebook大小 "bh_model": true, # 身体+手部模型 "gan": false }, "Data": { "pose": { "convert_to_6d": false, # 3D/6D旋转 "generate_length": 88, # 序列长度 "expression": true # 包含表情 }, "aud": { "feat_method": "mfcc", # MFCC特征 "aud_feat_dim": 64 # 64维音频特征 } }, "Train": { "epochs": 100, "learning_rate": { "generator_learning_rate": 1e-4 } } } # PixelCNN配置 (body_pixel.json) { "Model": { "model_name": "s2g_body_pixel", "composition": true, "code_num": 2048, "vq_path": "./experiments/.../ckpt-99.pth" # VQ-VAE路径 }, "Train": { "epochs": 100, "learning_rate": { "generator_learning_rate": 1e-4 } } }

class TrainWrapper(TrainWrapperBaseClass): def __init__(self, args, config): self.composition = self.config.Model.composition if self.composition: # 分离式：身体+手部 self.g_body = s2g_body( self.each_dim[1], embedding_dim=64, num_embeddings=config.Model.code_num, # 2048 num_hiddens=1024, num_residual_layers=2, num_residual_hiddens=512 ).to(self.device) self.g_hand = s2g_body( self.each_dim[2], embedding_dim=64, num_embeddings=config.Model.code_num, num_hiddens=1024, num_residual_layers=2, num_residual_hiddens=512 ).to(self.device) def init_optimizer(self): # 使用Adam优化器 self.g_body_optimizer = optim.Adam( self.g_body.parameters(), lr=self.config.Train.learning_rate.generator_learning_rate, betas=[0.9, 0.999] ) self.g_hand_optimizer = optim.Adam( self.g_hand.parameters(), lr=self.config.Train.learning_rate.generator_learning_rate, betas=[0.9, 0.999] )

核心代码：PixelCNN

class TrainWrapper(TrainWrapperBaseClass): def __init__(self, args, config): # 音频编码器 self.audioencoder = AudioEncoder( in_dim=64, num_hiddens=256, num_residual_layers=2, num_residual_hiddens=256 ).to(self.device) # PixelCNN生成器 self.generator = pixelcnn( 2048, # num_classes 512, # dim 10, # layer self.num_classes, self.audio, # 音频条件 self.bh_model # 身体+手部 ).to(self.device) # 加载预训练的VQ-VAE model_ckpt = torch.load(model_path, map_location=torch.device('cpu')) self.g_body.load_state_dict(model_ckpt['generator']['g_body']) self.g_hand.load_state_dict(model_ckpt['generator']['g_hand'])

class TrainWrapper(TrainWrapperBaseClass): def __init__(self, args, config): self.generator = s2g_face( n_poses=self.config.Data.pose.generate_length, # 88 each_dim=self.each_dim, dim_list=self.dim_list, training=not self.args.infer, device=self.device, identity=False if self.convert_to_6d else True, num_classes=self.num_classes, ).to(self.device) def init_params(self): # SMPL-X参数维度 if self.convert_to_6d: scale = 2 else: scale = 1 global_orient = round(3 * scale) jaw_pose = round(3 * scale) leye_pose = reye_pose = round(3 * scale) body_pose = round(63 * scale) left_hand_pose = right_hand_pose = round(45 * scale) expression = 100 # 表情参数 # 维度列表：[下巴, 眼睛+身体, 手部, 表情] self.each_dim = [jaw_dim, eye_dim + body_dim, hand_dim, face_dim]

🔬 技术创新点

1. 全身动作生成

  • SMPL-X模型：统一表示面部、身体和手部
  • 分离生成：面部和身体分开生成，便于独立控制
  • 端到端：从语音直接生成完整的3D人体动画
  • 高质量：VQ-VAE确保动作质量

2. VQ-VAE + PixelCNN架构

  • 离散表示：VQ-VAE将连续动作压缩为离散code
  • 自回归生成：PixelCNN实现高质量的序列生成
  • 音频条件：生成过程以音频特征为条件
  • 分离编码：身体和手部分开编码

3. 多语言泛化

  • 英语：主要训练语言
  • 法语：跨语言泛化能力
  • 歌曲：支持音乐性语音
  • MFCC特征：语言无关的音频表示

4. 面部表情生成

  • 100维表情：SMPL-X表情参数
  • 下巴姿态：与语音同步的下巴运动
  • 眼睛姿态：自然的眨眼和注视
  • Transformer：强大的序列建模能力
