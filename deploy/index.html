🛠️ 技术栈

生成模型

  • Diffusion Models (扩散模型)
  • GANs (生成对抗网络)
  • VAE / VQ-VAE (变分自编码器)
  • Normalizing Flows (标准化流)

序列建模

  • Transformer / TISA
  • LSTM / GRU
  • TCN (时序卷积网络)
  • PixelCNN / MaskGIT

多模态融合

  • Cross-Attention (交叉注意力)
  • CLIP (对比语言-图像预训练)
  • HuBERT / Wav2Vec (音频编码)
  • BERT / RoBERTa (文本编码)

离散化表示

  • Vector Quantization (向量量化)
  • Product Quantization (乘积量化)
  • Codebook Learning (码本学习)
  • Discrete VAE (离散VAE)

检索增强

  • Retrieval-Augmented Generation (RAG)
  • Memory Networks (记忆网络)
  • External Knowledge Base (外部知识库)
  • Nearest Neighbor Search (最近邻搜索)

评估指标

  • FGD (Fréchet Gesture Distance)
  • Beat Alignment (节拍对齐)
  • Diversity Score (多样性分数)
  • Semantic Consistency (语义一致性)
