CVPR 2024

ProbTalk: Towards Variable and Coordinated Holistic Co-Speech Motion Generation

作者：Fei Liu, Zhenyu Zhang, Yansong Tang, Jinpeng Liu, Yuhan Zhang, Yutao Feng, Yuwang Wang, Donglian Qi, Zihan Yan
机构：浙江大学、上海AI Lab、清华大学、慕尼黑工业大学
摘要： 我们提出了ProbTalk，一种用于可变且协调的整体协同语音动作生成的方法。 该方法通过概率建模实现多样化的手势生成，同时保持面部和身体动作的协调性。 ProbTalk采用两阶段训练策略：首先训练PQ-VAE进行动作离散化，然后训练基于Transformer的预测器和精炼器进行动作生成。 在SHOW数据集上取得了SOTA性能，支持全身（身体+面部）动作生成。

🎯 核心贡献

  • 概率Transformer架构 提出基于概率建模的Transformer架构，通过VQ-VAE离散化和自回归生成实现多样化动作输出。
  • 两阶段训练策略 第一阶段训练PQ-VAE进行动作离散化，第二阶段训练Predictor预测code，Refiner优化细节。
  • 全身动作协调生成 同时生成身体动作和面部表情，并通过设计保持两者之间的协调性。
  • MaskGIT采样策略 采用MaskGIT并行解码策略，提高推理速度同时保持生成质量。

核心代码：ResidualLearner

class ResidualLearner(nn.Module): def __init__(self, input_dim, is_audio, is_label, n_classes): super().__init__() self.input_dim = input_dim self.is_audio = is_audio self.is_label = is_label self.condi_dim = is_audio * 768 + is_label * 512 self.input_proj = nn.Conv1d(self.input_dim, 512, 1) self.condi_proj = nn.Conv1d(self.condi_dim, 512, 1) self.PE = PositionalEncoding(512, 1800) self.class_embed = nn.Embedding(n_classes, 512) # 6层Transformer Decoder decoder_layer = nn.TransformerDecoderLayer(512, 8) self.decoder = nn.TransformerDecoder(decoder_layer, 6) def forward(self, x, audio=None, label=None): # 处理条件（音频+标签） if self.is_audio and self.is_label: label_embed = self.class_embed(label).unsqueeze(-1) condition = torch.cat([audio, label_embed], dim=1) # 位置编码 x_pe = self.PE(torch.ones([x.shape[0], 1], dtype=torch.int32, device=x.device) * x.shape[2]) x = self.input_proj(x) x = (x.transpose(1, 2) + x_pe) # Transformer解码 output = self.decoder(x.permute(1, 0, 2), condition) return output

🔬 技术创新点

1. Product Quantization (PQ)

  • 分组量化：将特征分为4组分别量化，提高表达能力
  • Codebook学习：128个code，128维向量
  • fbhe类型：Face-Body-Hand-Expression分别建模
  • 残差量化：多级量化提高重建精度

2. 两阶段训练策略

  • 阶段1 - VQ训练：学习动作离散表示
  • 阶段2 - Predictor：自回归预测code序列
  • 阶段2 - Refiner：优化动作细节
  • 渐进优化：从粗到细逐步提升质量

3. MaskGIT并行采样

  • 并行解码：相比自回归大幅提升速度
  • 迭代精化：8步迭代逐步确定code
  • 置信度选择：每轮选择最确定的token
  • 平衡效率质量：快速且保持高质量

4. 全身协调性建模

  • 统一表示：身体和面部共享codebook
  • 联合训练：同时优化身体和面部
  • 身份编码：支持多说话者生成
  • 动作协调：保持身体-面部动作一致性
