CVPR 2024

DiffSHEG: A Diffusion-Based Approach for Real-Time Speech-driven Holistic 3D Expression and Gesture Generation

作者：Junming Chen, Yunfei Liu, Jianan Wang, Ailing Zeng, Yu Li, Qifeng Chen
机构：香港科技大学 (HKUST)、国际数字经济研究院 (IDEA)
摘要： 我们提出了DiffSHEG，一种基于扩散模型的实时语音驱动整体3D表情和手势生成方法。该方法能够同时生成与语音同步的3D面部表情和身体手势，实现整体（Holistic）的虚拟人动画生成。通过高效的DDIM采样策略，DiffSHEG能够在保持高质量的同时实现实时推理，为虚拟数字人、视频会议等应用提供了实用的解决方案。

🎯 核心贡献

  • 整体生成框架 (Holistic Generation) 首个基于扩散模型的实时语音驱动整体3D生成框架，同时生成面部表情和身体手势，确保面部和身体动作的自然协调。
  • 实时推理能力 (Real-time Inference) 采用DDIM（Denoising Diffusion Implicit Models）采样策略，将推理步数从1000步减少到25步，实现实时生成。
  • 多模态条件融合 有效融合音频特征（HuBERT）和文本特征，通过Transformer架构实现高质量的跨模态映射。
  • 周期性位置编码 创新的Periodic Positional Encoding机制，更好地建模时序依赖关系。

关键组件详解

🎵 HuBERT音频编码

使用预训练的HuBERT模型提取音频特征：

  • Facebook开源的自监督语音模型
  • 提取高层语义和韵律信息
  • 输出维度：768维
  • 比传统MFCC/Mel特征更丰富的表示

🤖 MotionTransformer

基于Transformer的扩散模型：

  • 8层Transformer Encoder
  • Latent dim: 512
  • 8头注意力机制
  • 支持Classifier-Free Guidance

⚡ DDIM采样

快速确定性采样策略：

  • 从1000步减少到25步
  • 保持生成质量的同时提速40倍
  • 确定性采样减少随机性
  • 适合实时应用场景

📍 周期性位置编码

Periodic Positional Encoding：

  • 周期：25帧
  • 最大序列长度：600帧
  • 更好地建模周期性动作
  • 比标准位置编码更适合动作生成

数据集

BEAT Dataset

大规模多模态对话手势数据集

  • 76小时录制数据
  • 30位说话者，4种语言
  • 包含情感和语义标注

演讲场景数据集

  • 演讲风格手势

核心代码：周期性位置编码

class PeriodicPositionalEncoding(nn.Module): def __init__(self, d_model, dropout=0.1, period=25, max_seq_len=600): super().__init__() self.dropout = nn.Dropout(p=dropout) pe = torch.zeros(period, d_model) position = torch.arange(0, period, dtype=torch.float).unsqueeze(1) div_term = torch.exp(torch.arange(0, d_model, 2).float() * (-math.log(10000.0) / d_model)) pe[:, 0::2] = torch.sin(position * div_term) pe[:, 1::2] = torch.cos(position * div_term) pe = pe.unsqueeze(0).repeat(1, (max_seq_len//period) + 1, 1) self.register_buffer('pe', pe) def forward(self, x): x = x + self.pe[:, :x.size(1), :] return x

🔬 技术创新点

1. 整体生成 vs 分离生成

  • 联合建模：同时生成表情和手势，确保两者协调一致
  • 共享条件：使用相同的音频条件驱动面部和身体
  • 时序对齐：保持面部和身体动作的时间同步

2. DDIM快速采样

  • 确定性采样：相比DDPM的随机采样，DDIM更稳定
  • 步数压缩：从1000步压缩到25步，提速40倍
  • 质量保证：在加速的同时保持生成质量

3. HuBERT音频特征

  • 自监督预训练：利用大规模语音数据预训练
  • 语义丰富：包含语音的语义和韵律信息
  • 比传统特征更好：优于MFCC和Mel-spectrogram

4. Stylization Block

  • 通过时间嵌入调制特征
  • 引入条件自适应归一化
  • 增强模型的表达能力
