ICCV 2025

SemGes: Semantics-aware Co-Speech Gesture Generation using Semantic Coherence and Relevance Learning

作者：Lanmiao Liu, Esam Ghaleb, Aslı Özyürek, Zerrin Yumak
机构：Utrecht University
摘要： 我们提出了SemGes，一种语义感知的协同语音手势生成方法。 该方法通过语义一致性学习（Semantic Coherence Learning）和语义相关性学习（Semantic Relevance Learning）来生成与语音语义高度一致的手势。 采用两阶段训练策略：首先训练VQ-VAE对手势进行离散化编码，然后训练语义Transformer在潜在空间生成手势序列。 支持手部（hand）和身体（body）的分离生成，并在BEAT和TED数据集上进行了验证。

🎯 核心贡献

  • 语义一致性学习（Semantic Coherence Learning） 确保生成的手势在语义上与语音内容保持一致，通过跨模态注意力机制学习音频-文本-手势的语义对齐。
  • 语义相关性学习（Semantic Relevance Learning） 学习手势与语音之间的语义相关性，生成更自然、更有意义的手势动作。
  • 分离式手势生成 支持手部（hand）和身体（body）的分离生成，分别使用独立的VQ-VAE进行编码和解码。
  • 两阶段训练策略 第一阶段训练VQ-VAE进行手势离散化，第二阶段训练语义Transformer在潜在空间生成手势。

核心代码：语义Transformer

class SemanticsLatentTransformer(nn.Module): def __init__(self, args): super().__init__() self.args = args # 位置编码 self.pos_encoder = PositionalEncoding(d_model=args.hidden_size) # Transformer层 self.transformer_layers = nn.ModuleList([ nn.TransformerEncoderLayer( d_model=args.hidden_size, nhead=8, dim_feedforward=2048, dropout=0.1 ) for _ in range(args.n_layer) ]) # 跨模态注意力 self.cross_attention = CrossModalAttention( in_dim=args.hidden_size, dim=args.hidden_size, heads=8 ) def forward(self, audio_feat, text_feat, speaker_id): # 融合音频和文本特征 fused_feat = self.fusion_layer(audio_feat, text_feat) # 添加位置编码 fused_feat = self.pos_encoder(fused_feat) # Transformer编码 for layer in self.transformer_layers: fused_feat = layer(fused_feat) # 生成手势潜在表示 hand_latent = self.hand_decoder(fused_feat) body_latent = self.body_decoder(fused_feat) return hand_latent, body_latent

核心代码：语义一致性损失

# 语义一致性损失 def semantic_coherence_loss(self, gesture_emb, audio_emb, text_emb): # 计算余弦相似度 audio_gesture_sim = self.cosine_sim(gesture_emb, audio_emb) text_gesture_sim = self.cosine_sim(gesture_emb, text_emb) audio_text_sim = self.cosine_sim(audio_emb, text_emb) # 语义一致性：手势应该与音频和文本都保持一致 coherence_loss = 1 - (audio_gesture_sim + text_gesture_sim) / 2 return coherence_loss # 语义相关性损失 def semantic_relevance_loss(self, pred_gesture, target_gesture, semantic_weight): # 基础重建损失 rec_loss = self.rec_loss(pred_gesture, target_gesture) # 根据语义相关性加权 weighted_loss = rec_loss * semantic_weight return weighted_loss.mean()

核心代码：VQ-VAE

class VQVAEConvZero_1(nn.Module): def __init__(self, args): super().__init__() self.args = args # 编码器 self.encoder = nn.Sequential( nn.Conv1d(in_channels, hidden_dim, kernel_size=3, padding=1), nn.ReLU(), nn.Conv1d(hidden_dim, hidden_dim, kernel_size=3, padding=1), nn.ReLU(), ) # 量化器 self.quantizer = VectorQuantizer( num_embeddings=args.vae_codebook_size, embedding_dim=args.vae_length ) # 解码器 self.decoder = nn.Sequential( nn.Conv1d(hidden_dim, hidden_dim, kernel_size=3, padding=1), nn.ReLU(), nn.Conv1d(hidden_dim, out_channels, kernel_size=3, padding=1), ) def forward(self, x): # 编码 z = self.encoder(x) # 量化 z_q, loss, indices = self.quantizer(z) # 解码 x_recon = self.decoder(z_q) return x_recon, loss, indices

🔬 技术创新点

1. 语义一致性学习

  • 跨模态对齐：通过余弦相似度学习音频-文本-手势的语义对齐
  • 一致性约束：确保生成的手势在语义上与语音内容保持一致
  • 多模态融合：有效融合音频和文本信息

2. 语义相关性学习

  • 语义加权：根据语义相关性对重建损失进行加权
  • 动态调整：自适应地调整不同语义内容的手势生成
  • 自然性提升：使生成的手势更符合自然语言表达习惯

3. 分离式手势生成

  • Hand VQ-VAE：专门编码手部精细动作（228维）
  • Body VQ-VAE：专门编码身体姿态（54维）
  • 独立控制：可以分别控制手部和身体的生成
  • 联合优化：在语义Transformer中联合优化

4. 两阶段训练策略

  • 第一阶段：训练VQ-VAE学习高质量的离散表示
  • 第二阶段：在潜在空间训练语义Transformer
  • 稳定训练：分阶段训练提高模型稳定性
  • 高效生成：在紧凑的潜在空间生成手势
