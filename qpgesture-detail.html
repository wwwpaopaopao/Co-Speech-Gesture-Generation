CVPR 2023

QPGesture: Quantization-Based and Phase-Guided Motion Matching for Natural Speech-Driven Gesture Generation

作者：Sicheng Yang, Zhiyong Wu, Minglei Li, Zhensong Zhang, Lei Hao, Weihong Bao, Ming Cheng, Long Xiao
机构：清华大学、腾讯AI Lab
摘要： 我们提出了QPGesture，一种基于量化和相位引导的动作匹配方法，用于自然的语音驱动手势生成。 该方法通过VQ-VAE将动作离散化到codebook，然后使用KNN算法在codebook中搜索最匹配的手势序列。 同时引入相位信息（Phase）来指导动作匹配，确保生成动作的时间一致性和自然性。 在BEAT数据集上取得了SOTA性能，支持特定说话者的个性化手势生成。

🎯 核心贡献

  • 基于量化的动作匹配 使用VQ-VAE将动作离散化到codebook，通过KNN搜索实现高质量的动作匹配，避免了神经网络生成的不确定性。
  • 相位引导机制 引入相位信息（Phase）指导动作匹配过程，通过PAE（Phase Autoencoder）提取动作的周期性特征。
  • 个性化手势生成 支持特定说话者的个性化手势生成，通过学习说话者的手势风格特征。
  • 音频多特征融合 融合WavLM、Wav2Vec、MFCC等多种音频特征，提高音频-动作匹配的准确性。

核心代码：GestureKNN

class GestureKNN(object): def __init__(self, feat_train, motn_train, control_mask, n_aud_feat=112, n_body_feat=96, n_joints=165, step_sz=8): self.n_aud_feat = n_aud_feat self.n_body_feat = n_body_feat self.n_joints = n_joints self.step_sz = step_sz self.feat_train = feat_train self.motn_train = motn_train self.control_mask = control_mask def wavvq_distances(self, ls1, ls2, mode='sum'): # 使用Levenshtein距离计算WavVQ相似度 def ls2str(ls): ls = ls.reshape(NUM_AUDIO_FEAT_FRAMES, -1).transpose() str1 = ''.join([chr(int(i)) for i in ls[0]]) str2 = ''.join([chr(int(i)) for i in ls[1]]) return str1, str2 ls1_group1_str, ls1_group2_str = ls2str(ls1) ls2_group1_str, ls2_group2_str = ls2str(ls2) return Levenshtein.distance(ls1_group1_str, ls2_group1_str) + \ Levenshtein.distance(ls1_group2_str, ls2_group2_str)

核心代码：PAE Phase Autoencoder

class Model(nn.Module): def __init__(self, input_channels, embedding_channels, time_range, key_range, window): super(Model, self).__init__() self.input_channels = input_channels # 3 * joints self.embedding_channels = embedding_channels # 8 phase channels self.time_range = time_range # 121 frames self.window = window # 2.0 seconds # FFT频率计算 self.freqs = Parameter(torch.fft.rfftfreq(time_range)[1:] * (time_range * self.time_scale) / self.window, requires_grad=False) # 编码器 self.conv1 = nn.Conv1d(input_channels, intermediate_channels, time_range) self.conv2 = nn.Conv1d(intermediate_channels, embedding_channels, time_range) # 相位提取 self.fc = torch.nn.ModuleList() for i in range(embedding_channels): self.fc.append(nn.Linear(time_range, 2)) # 振幅+相位 # 解码器 self.deconv1 = nn.Conv1d(embedding_channels, intermediate_channels, time_range) self.deconv2 = nn.Conv1d(intermediate_channels, input_channels, time_range)

🔬 技术创新点

1. 基于检索的生成范式

  • 避免生成不确定性：相比神经网络生成，检索方法更稳定
  • 高质量保证：从真实数据中选择最匹配的动作
  • 可解释性强：可以追踪匹配来源
  • 个性化容易：针对特定说话者构建数据库

2. 多特征音频表示

  • WavLM：大规模预训练语音模型
  • Wav2Vec：自监督语音表示
  • MFCC：传统语音特征
  • 多特征融合：提高匹配准确性

3. 相位引导机制

  • 周期性建模：捕捉动作的周期性特征
  • 时间对齐：确保动作与音频节奏对齐
  • 平滑过渡：相邻动作片段平滑衔接
  • PAE网络：自动学习相位特征

4. VQ-VAE离散化

  • 高效表示：将连续动作压缩为离散code
  • 快速检索：基于code的KNN搜索
  • 可扩展性：易于扩展到大规模数据库
  • 重建质量：高质量的VQ-VAE解码

💡 应用场景

  • 个性化助手：学习用户习惯的手势风格
  • 实时应用：高效的检索算法支持实时生成
